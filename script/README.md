# かおディスバトル（仮）

自分で描いた顔でCPUとツッコミ対決する、日本語ブラウザゲームです。依存ライブラリ・ビルド・APIキーなしでデモを遊べます。Ollamaを使うと、ローカルLLMが採点とCPUの返答を担当します。オンライン対戦は含みません。

## 起動

Python 3.10以降を用意し、このフォルダで実行します。

```bash
python3 server.py
```

ブラウザで **http://127.0.0.1:8000** を開いてください。終了は Ctrl+C。ポートを変える場合は `python3 server.py --port 8001`。HTMLを直接開かず、HTTPサーバー経由で利用してください。

1. ペン・消しゴム・色・太さで顔を描きます。元に戻す（直近50操作）と全消去に対応。消去後に画素が残っていなければ開始できません。
2. デモ判定、または接続済みのローカルLLMを選んでバトルを開始。
3. 顔へのツッコミを入力。あなた→CPUの順で3回ずつ攻撃します。
4. 初期HPは100、1攻撃のダメージは0〜30。全6攻撃が終わった残りHPで勝敗を決め、同じなら引き分け。同じ顔で再戦、または顔の編集に戻れます。

## ローカルLLM（Ollama）

[Ollama](https://ollama.com/)をインストールし、使いたいモデルをあらかじめインストールしてください。本アプリはモデルの自動ダウンロードを行いません。

```bash
ollama serve
ollama list
```

Ollamaの常駐サービスが既に動いていれば `ollama serve` の追加起動は不要です。

使用モデルは **`config.py`** で変更できます。

```python
JUDGE_MODE = "local"  # "demo" にするとデモ判定で起動
OLLAMA_MODEL = "qwen3-vl:4b-instruct"
OLLAMA_URL = "http://127.0.0.1:11434"
```

モデルは先に `ollama pull qwen3-vl:4b-instruct` などで取得してください。モデルが新しいOllamaを要求する場合は、先にOllama本体を更新します。

**設定変更後に `server.py` を再起動し、ブラウザを再読み込みすると、指定モデルに自動接続します。** モデル名をHTMLやJavaScriptに書く必要はありません。未取得・接続失敗時には理由を表示してバトル開始を止めます。画面でデモ判定に切り替えることもできます。

環境変数 `OLLAMA_MODEL` / `OLLAMA_URL` を指定した場合は `config.py` より優先します。画面から一時的に別モデルを使う場合は「モデル一覧を取得 → モデルを選ぶ → このモデルに接続」で変更できます。画面での変更はファイルには保存されません。

- 標準接続先は `http://127.0.0.1:11434`。変更はサーバー起動時の環境変数 `OLLAMA_URL` で指定できます。接続先は自分で管理するサービスを指定してください。
- `/api/show` の `capabilities` に `vision` があるモデルには、対象の顔をPNG画像で渡します。描いた顔はCPUの発言生成とCPU攻撃の採点にも使用します。
- **テキスト専用モデルでは顔画像を渡しません。** 画面に「テキスト専用」と表示し、言葉の工夫と重複だけを採点。CPUにも画像を見たかのように断言しないよう指示します。画像への一致点は0点扱いです。
- モデルへの指示は、たとえの工夫0〜15・重複の少なさ0〜5・画像の特徴との一致0〜10。過激さ・文字数では加点しないよう指示し、サーバーとゲーム処理でダメージを0〜30に制限します。ただし、モデルの採点の公平性・指示遵守は保証できません。
- 1ラウンドにつき、プレイヤー採点→CPU発言生成→CPU採点の3回推論します。モデルとPCによって待ち時間が変わります。各サーバー呼び出しは120秒でタイムアウトします。
- 通信・応答形式のエラー時にはそのラウンドのHP・履歴を更新せず、入力を残して再送信できます。デモへ勝手に切り替えません。
- APIキーは不要です。将来の外部AI接続でもキーはサーバー側で管理してください。

Ollama APIの仕様: [Chat](https://docs.ollama.com/api/chat)、[モデル情報](https://docs.ollama.com/api/show)。顔画像と発言はPythonサーバー経由で設定したOllamaへ送ります。本アプリ自身は画像・発言を保存しません。画面を更新するとお絵描き・対戦内容は消えます。

## デモ判定

画像を解析しない仮採点です。たとえの言い回し・顔の部位を表す単語・遊びのある単語を検出し、過去の発言との文字列・二文字組の類似度で重複を減点します。文字数や過激さによる加点はありません。CPUは3種類の定型文です。実際の顔と発言の一致や、本当の面白さは判定できません。画面・ログで「デモ判定」と明示しています。

## ファイル構成と差し替え

- `index.html` / `style.css`：レスポンシブUI、HP・ログ・攻撃演出。
- `drawing.js`：Pointer Eventsによる描画。マウス・タッチ対応、透過画素による空白判定。
- `game.js`：HP、3ラウンド、勝敗、非同期ロック、成功時のみ確定する状態更新。
- `judge.js`：デモ採点・CPU定型文。
- `local-judge.js`：同一オリジンのPython APIを呼び出すLLMプロバイダー。
- `config.py`：起動時の判定モード・モデル名・Ollama接続先。
- `server.py`：静的ファイル配信、Ollama接続、画像対応の検出、JSON応答の検証。

採点プロバイダーは `evaluate({text, history, targetImage, round, actor}) → {damage, reason}` と `cpuAttack({round, targetImage, history}) → string` を実装します。ゲーム進行を変更せずプロバイダーを差し替えられます。

## 検証

サーバー処理はPython標準ライブラリだけで検証できます。

```bash
python3 -m unittest discover -s tests -v
```

サーバーを起動し **http://127.0.0.1:8000/tests/index.html** を開くと、ブラウザ内でゲーム処理10項目（3ラウンド、勝敗、重複、二重送信、エラー時の復帰、ダメージ制限、描画・消去・undo、プロバイダー契約など）を確認できます。

`tests/browser_check.py` は追加の開発用CDP検証です。Python `websockets` と、デバッグポート9222で起動したChromium系ブラウザ、ポート8001で起動した本サーバーが必要です。通常のプレイには不要です。実Ollamaモデルへの推論も実行します。

`tests/config_browser_check.py` では、プログラム設定からのモデル自動接続、未取得モデル時の開始防止、デモ設定、設定読込失敗時の表示をモックAPIと実ブラウザで検証できます。ブラウザとサーバーの起動条件は上記CDP検証と同じです。
